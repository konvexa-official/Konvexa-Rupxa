# Rupxa

### Your money, clearly mapped.

Rupxa is a simple finance app that helps you track your expenses and split shared expenses with friends, family, or groups.

## Features

- 🔐 Secure user login
- 💰 Track daily expenses
- 📊 View your spending dashboard
- 👥 Create and manage expense groups
- ➕ Add multiple expenses to a group
- 🧮 Split expenses equally or with custom amounts
- 🔄 Real-time updates for group members
- 📝 See who changed what and when
- 🗑️ Delete expenses with a reason
- 🔎 Connect with users using email or phone
- 📱 Responsive design for mobile and desktop

## Design

## Privacy

Your financial information is kept private and shared only with authorized users and groups.
